# 已开发文档 — 智能学习助手

最后更新: 2026-06-05

## 说明

本文档记录所有已完成开发的功能模块。

---

## 基础架构

| 任务 | 文件 | 说明 |
|------|------|------|
| 项目骨架 | `main.py`, `src/config.py`, `src/logger.py` | 统一入口、配置管理、日志系统 |
| 数据库 | `src/database/db_manager.py` | MySQL 连接池 + 9 张表（sessions/messages/documents/knowledge_diagnosis/favorites/reading_progress/bookmarks/tags/message_tags） |
| 会话仓库 | `src/database/session_repo.py` | 会话+消息 CRUD，支持分页查询 |
| 文档仓库 | `src/database/document_repo.py` | 文档元数据 CRUD |
| 阅读进度仓库 | `src/database/reading_repo.py` | 阅读进度 CRUD |
| 书签仓库 | `src/database/bookmark_repo.py` | 书签 CRUD |
| 标签仓库 | `src/database/tag_repo.py` | 标签+消息标签 CRUD |

## 数据层

| 任务 | 文件 | 说明 |
|------|------|------|
| PDF 解析 | `src/data/pdf_parser.py` | PyMuPDF + PaddleOCR 扫描件支持 |
| 文本分块 | `src/data/chunker.py` | 递归语义分块，chunk_size=500 |
| 向量库 | `src/data/vector_store.py` | Chroma + BAAI/bge-small-zh-v1.5 中文嵌入 |

## RAG 逻辑层

| 任务 | 文件 | 说明 |
|------|------|------|
| LangGraph 状态机 | `src/rag/state.py`, `retrieve.py`, `grade.py`, `generate.py`, `rewrite.py`, `graph.py` | 自纠正检索循环 |
| LLM 客户端 | `src/rag/llm_client.py` | Ollama(主) + DeepSeek(备) 自动降级+指数退避重试 |
| 查询引擎 | `src/rag/query_engine.py` | 多轮上下文增强、聊天历史 RAG |
| 会话管理 | `src/rag/session_manager.py` | 会话/笔记/收藏封装 |
| 文档管理 | `src/rag/document_manager.py` | 文档上传流水线 |
| 门面服务 | `src/rag/rag_service.py` | 统一接口（40+ 方法） |
| 思维导图生成 | `src/rag/mindmap_generator.py` | Mermaid graph LR + Map-Reduce |
| 文档全文提取 | `src/rag/document_processor.py` | 从 PDF 提取全文用于生成 |
| 聊天历史 RAG | `src/rag/chat_history_store.py` | 独立 Chroma 集合存储 Q&A |
| 学习诊断 | `src/rag/diagnosis.py` | 知识点提取+计数+建议 |
| 智能出题 | `src/rag/quiz_generator.py` | 选择题/填空题/简答题生成+判分 |
| 闪卡生成 | `src/rag/flashcard_generator.py` | 问答对闪卡生成 |
| 文档对比 | `src/rag/compare_generator.py` | 两文档差异分析 |
